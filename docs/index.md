# Vernie OS Knowledge Bundle

Open Knowledge Format (OKF v0.2) documentation for the custom pure-MIT native-C firmware and Chromebook-first Web Bluetooth Cockpit for LEGO BOOST Vernie (Set 17101 / Move Hub 88006).

# Knowledge Domains

* [Architecture](architecture/) - System architecture for Vernie OS bare-metal firmware and the Web Bluetooth Cockpit PWA.
* [Hardware](hardware/) - Verified STM32F070RB Move Hub memory map, peripherals, and Vernie mechanical constraints.
* [Protocol](protocol/) - Layer-2 binary AppData BLE protocol and LWP3 bootloader flashing wire specification.
* [Playbooks](playbooks/) - Operational procedures for Chromebook flashing, recovery, and hardware acceptance testing.
* [Computations](computations/) - OKF v0.2 Attested Computations for bootloader checksums and Flash/SRAM safety budgets.
* [References](references/) - Executor runbooks and deterministic Python attesters backing attested computations.
