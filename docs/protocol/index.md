# Protocol

* [BLE AppData Binary Protocol](ble-appdata.md) - Layer-1 Pybricks GATT framing and Layer-2 Vernie RX (<=17 B) and TX (18 B) binary packets.
* [LWP3 Bootloader Flashing Protocol](lwp3-bootloader.md) - Unbrickable Move Hub BLE DFU protocol (0x1625/0x1626), 14-byte chunking, and v2.0.0 packaging.
